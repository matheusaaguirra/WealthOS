# Contratos da primeira entrega
Stack: Angular 20.3 / NestJS 11 / Prisma 6 / PostgreSQL 16. npm workspaces. Node 22.12+.
Escopo: versão inicial local; sem deploy, pagamentos, Open Finance ou alegação de SaaS pronto.
Frontend: demo local com dados fictícios isolados em localStorage. Pode alternar para API real por configuração visível. Rotas/telas: dashboard, lançamentos, contas, orçamentos, metas. UI em pt-BR, BRL. Sem botões sem ação.
API: /api/health; /api/auth/register, /api/auth/login; /api/accounts GET/POST; /api/transactions GET/POST; /api/transactions/:id/reverse POST; /api/summary GET. Auth JWT, workspace inferido do token, nunca aceito do body. Montantes em centavos inteiros seguros, positivos e no máximo 1 bilhão; tipos INCOME/EXPENSE. Account openingBalanceCents pode ser negativo. Transaction {id,accountId,description,amountCents,type,category,date,idempotencyKey,reversedAt?}; Account {id,name,institution,color,openingBalanceCents}. date YYYY-MM-DD, 2000 a 2100. Idempotência workspace+key, rejeitar payload diferente com a mesma chave. API usa banco PostgreSQL real, sem fallback fingido.
Core financeiro @wealthos/finance: exportar type Entry={id:string,accountId:string,amountCents:number,type:'INCOME'|'EXPENSE',date:string,reversedAt?:string|null}; funções parseMoneyToCents(input:string):number (entrada BR com vírgula, rejeitar precisão >2 casas), validateAmount(cents:number):void, balance(openingBalanceCents:number,entries:Entry[]):number (exclui estornados), summarize(entries:Entry[],month:string):{incomeCents:number,expenseCents:number,balanceCents:number}, splitInstallments(totalCents:number,count:number):number[] (resto distribuído nas primeiras parcelas, soma exata), assertNoDuplicate(entries:Entry[]):void (por id), validateDate(date:string):void. Testes independentes devem importar estas funções. Dados 100% fictícios.
